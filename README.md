# agent-kit

A kit that any repo can adopt in one step so cloud agents fix its production errors around the clock, while nothing merges unless it passes a gate the agents cannot override.

**Status:** design accepted (2026-11-10), building.

- [Design record](docs/design/2026-11-10-agent-kit.md): intent, decisions, and the contracts builders implement against.
- [Invariants](docs/design/invariants.md): the rules every change must keep, each with its check.
